# Tools and Resources

## Tools Used

| Tool | Purpose |
|---|---|
| VMware Workstation | Hosted the Ubuntu Server VM on an isolated NAT network |
| Ubuntu Server 24.04 | Guest OS for the server being configured |
| Nginx | Web server (Part 1) |
| OpenSSH | Key-based remote administration (Part 2) |
| UFW (Uncomplicated Firewall) | Static, port-based firewall front-end for iptables/netfilter (Part 3) |
| Fail2ban | Dynamic, log-driven brute-force protection (Part 3-4) |
| Windows PowerShell | Client-side SSH sessions and the brute-force test simulation |
